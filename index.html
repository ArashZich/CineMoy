04 — Install

Two minutes, once.

Android TV

  1. Install Downloader from the Play Store on your TV.
  2. Allow it to install apps: Settings → Apps → Security → Unknown sources.
  3. In Downloader, open cinemoy.fun and pick your download.
  4. Open CineMoy from your apps.

Windows

  1. Download the Installer and open it.
  2. If SmartScreen appears: More info → Run anyway.
  3. Open CineMoy from the Start menu.
  4. Optional: add a free SubDL key in Settings for more Farsi subtitles.

macOS

  1. Open the .dmg and drag CineMoy into Applications.
  2. The app isn't signed by Apple yet. Open Terminal once and run xattr -cr /Applications/CineMoy.app
  3. Open CineMoy from Applications.

Linux

  1. AppImage: right-click → Properties → Allow executing as program, then double-click it.
  2. Ubuntu / Debian: run sudo apt install ./cinemoy_*.deb in the download folder.
  3. Open CineMoy from your app menu.

CineMoy doesn't host any videos; it finds streams from third-party sources. What you watch is your responsibility — only watch content you have the right to access in your country.
