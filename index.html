How to install

CineMoy isn't in an app store yet, so your device asks you to confirm once.

Windows

  1. Download the Installer and open it.
  2. If Windows SmartScreen appears, click More info → Run anyway.
  3. Open CineMoy from the Start menu.

Android TV

  1. Install the free Downloader app from the Play Store on your TV.
  2. Allow it to install apps: Settings → Apps → Security → Unknown sources.
  3. In Downloader, open cinemoy.fun and choose your download.
  4. Open CineMoy from your apps.

Tip: add a free SubDL API key in CineMoy's Settings for many more Farsi subtitles.

CineMoy doesn't host any videos. It finds streams from third-party sources; what you watch is your responsibility. Only watch content you have the right to access in your country.
